# Backend Integration Guide

This guide explains how to integrate the **oelala** backend (Python/FastAPI) with **oelala-storage** (Go service).

## Overview

The oelala-storage service provides S3-compatible object storage for media files generated by the oelala platform. The backend communicates with storage via HTTP API for uploading, downloading, and managing user media.

## Authentication Flow

### JWT from Supabase

The oelala backend uses Supabase for authentication. When making requests to oelala-storage:

1. **Extract JWT from Supabase session**
   ```python
   from supabase import create_client
   
   supabase = create_client(supabase_url, supabase_key)
   session = supabase.auth.get_session()
   jwt_token = session.access_token
   user_id = session.user.id
   ```

2. **Pass JWT in Authorization header**
   ```python
   import httpx
   
   headers = {
       "Authorization": f"Bearer {jwt_token}",
       "Content-Type": "application/octet-stream"
   }
   
   async with httpx.AsyncClient() as client:
       response = await client.put(
           f"http://localhost:7990/users/{user_id}/media/video.mp4",
           headers=headers,
           content=file_content
       )
   ```

3. **Storage service validates JWT**
   
   The storage service validates the JWT token using a configured `TokenValidator` function that:
   - Verifies the JWT signature
   - Extracts user_id and tier information
   - Returns a `UserContext` with user details
   
   ```go
   type UserContext struct {
       UserID    string
       TierID    string    // free, creator, pro, studio
       Roles     []string
       ExpiresAt time.Time
   }
   ```

### Alternative: API Keys

For service-to-service communication or testing:

```python
headers = {
    "X-API-Key": "your-api-key-here"
}
```

API keys are configured in the storage service configuration file.

## Storage Path Conventions

### User Isolation

All user files are stored under a user-specific namespace:

```
/users/{user_id}/media/{filename}
```

**Examples:**
- `/users/123e4567-e89b-12d3-a456-426614174000/media/generated_video.mp4`
- `/users/123e4567-e89b-12d3-a456-426614174000/media/avatar.png`
- `/users/123e4567-e89b-12d3-a456-426614174000/media/audio/track.mp3`

### Path Structure

```
/users/{user_id}/
├── media/
│   ├── images/
│   ├── videos/
│   └── audio/
├── temp/
└── exports/
```

### Best Practices

1. **Use user_id from JWT**: Always derive the user_id from the authenticated token
2. **Organize by type**: Group files by media type (images, videos, audio)
3. **Use descriptive names**: Include timestamps or generation IDs in filenames
4. **Avoid collisions**: Use UUIDs or timestamps to prevent filename conflicts

```python
import uuid
from datetime import datetime, timezone

def generate_storage_path(user_id: str, media_type: str, extension: str) -> str:
    """Generate a unique storage path for a media file."""
    timestamp = datetime.now(timezone.utc).strftime("%Y%m%d_%H%M%S")
    unique_id = uuid.uuid4().hex[:8]
    filename = f"{timestamp}_{unique_id}.{extension}"
    return f"/users/{user_id}/media/{media_type}/{filename}"

# Example usage
path = generate_storage_path(user_id, "videos", "mp4")
# Returns: /users/{user_id}/media/videos/20260112_143022_a1b2c3d4.mp4
```

## Auto-Upload After Generation

### Workflow

1. **Generate media** (video, audio, or image)
2. **Check quota** before upload
3. **Upload to storage**
4. **Record metering event**
5. **Return storage URL** to user

### Implementation Example

```python
from typing import Optional
import httpx
from pathlib import Path

class StorageClient:
    def __init__(self, base_url: str = "http://localhost:7990"):
        self.base_url = base_url
        self.client = httpx.AsyncClient(timeout=300.0)  # 5 min timeout
    
    async def __aenter__(self):
        """Async context manager entry."""
        return self
    
    async def __aexit__(self, exc_type, exc_val, exc_tb) -> None:
        """Async context manager exit."""
        await self.client.aclose()
    
    async def upload_generated_media(
        self,
        user_id: str,
        jwt_token: str,
        file_path: Path,
        media_type: str
    ) -> Optional[dict]:
        """
        Upload generated media to storage with quota check.
        
        Args:
            user_id: User ID from Supabase
            jwt_token: JWT token from Supabase session
            file_path: Local path to generated file
            media_type: Type of media (video, audio, image)
            
        Returns:
            Upload response with metadata or None if quota exceeded
        """
        # 1. Check quota before upload
        file_size = file_path.stat().st_size
        quota_check = await self.check_quota(user_id, jwt_token, file_size)
        
        if not quota_check["allowed"]:
            return {
                "error": "quota_exceeded",
                "message": quota_check["message"],
                "upgrade_url": "https://oelala.ai/upgrade"
            }
        
        # 2. Generate storage path
        storage_path = generate_storage_path(
            user_id, 
            media_type, 
            file_path.suffix.lstrip('.')
        )
        
        # 3. Upload file
        headers = {
            "Authorization": f"Bearer {jwt_token}",
            "Content-Type": self._get_content_type(file_path)
        }
        
        with open(file_path, "rb") as f:
            response = await self.client.put(
                f"{self.base_url}{storage_path}",
                headers=headers,
                content=f
            )
        
        if response.status_code == 201:
            result = response.json()
            return {
                "success": True,
                "path": storage_path,
                "url": f"{self.base_url}{storage_path}",
                "size": result["size"],
                "hash": result["hash"],
                "content_type": result["content_type"]
            }
        else:
            return {
                "error": "upload_failed",
                "status": response.status_code,
                "message": response.text
            }
    
    async def check_quota(
        self, 
        user_id: str, 
        jwt_token: str, 
        file_size: int
    ) -> dict:
        """Check if user has enough quota for the upload."""
        # This would call a quota check endpoint
        # For now, implement locally based on tier limits
        tier_quotas = {
            "free": 2 * 1024**3,      # 2 GB
            "creator": 50 * 1024**3,  # 50 GB
            "pro": 200 * 1024**3,     # 200 GB
            "studio": 1024**4         # 1 TB
        }
        
        # Get current usage (would call storage API)
        # For now, simplified example
        return {
            "allowed": True,  # Check actual usage
            "message": "Quota available"
        }
    
    def _get_content_type(self, file_path: Path) -> str:
        """Determine content type from file extension."""
        extension_map = {
            ".mp4": "video/mp4",
            ".webm": "video/webm",
            ".mp3": "audio/mpeg",
            ".wav": "audio/wav",
            ".png": "image/png",
            ".jpg": "image/jpeg",
            ".jpeg": "image/jpeg",
            ".gif": "image/gif"
        }
        return extension_map.get(file_path.suffix.lower(), "application/octet-stream")
```

## Quota Checking Before Generation

### Quota Limits by Tier

| Tier    | Storage Quota | Retention  |
|---------|---------------|------------|
| Free    | 2 GB          | 30 days    |
| Creator | 50 GB         | Unlimited  |
| Pro     | 200 GB        | Unlimited  |
| Studio  | 1 TB          | Unlimited  |

### Pre-Generation Quota Check

**Always check quota before starting generation** to avoid wasting compute resources:

```python
async def can_generate(user_id: str, tier_id: str, estimated_size_mb: int) -> tuple[bool, str]:
    """
    Check if user can generate media of given size.
    
    Args:
        user_id: User ID
        tier_id: User's tier (free, creator, pro, studio)
        estimated_size_mb: Estimated output size in MB
        
    Returns:
        (allowed, message) tuple
    """
    tier_quotas = {
        "free": 2048,      # 2 GB in MB
        "creator": 51200,  # 50 GB in MB
        "pro": 204800,     # 200 GB in MB
        "studio": 1048576  # 1 TB in MB
    }
    
    quota_mb = tier_quotas.get(tier_id, tier_quotas["free"])
    
    # Get current usage from storage service
    async with StorageClient() as storage:
        usage = await storage.get_usage(user_id)
        used_mb = usage["used_bytes"] / (1024 * 1024)
    
    available_mb = quota_mb - used_mb
    
    if estimated_size_mb > available_mb:
        return False, (
            f"Insufficient storage. Need {estimated_size_mb}MB, "
            f"have {available_mb:.1f}MB available. "
            f"Upgrade at https://oelala.ai/upgrade"
        )
    
    return True, "Quota available"

# Example usage in API endpoint
@app.post("/api/generate/video")
async def generate_video_endpoint(
    request: VideoGenerationRequest,
    user: User = Depends(get_current_user)
):
    # Estimate output size (e.g., 1080p video ~10MB per minute)
    estimated_mb = request.duration_seconds / 60 * 10
    
    # Check quota first
    allowed, message = await can_generate(
        user.id, 
        user.tier_id, 
        int(estimated_mb)
    )
    
    if not allowed:
        raise HTTPException(
            status_code=402,  # Payment Required
            detail=message
        )
    
    # Proceed with generation
    result = await generate_and_upload_video(
        user.id,
        user.jwt_token,
        user.tier_id,
        request.prompt
    )
    
    return result
```

## Error Handling

### Common Errors

#### 1. Quota Exceeded (402 Payment Required)

```python
try:
    result = await storage.upload_generated_media(...)
except httpx.HTTPStatusError as e:
    if e.response.status_code == 402:
        return {
            "error": "quota_exceeded",
            "message": "Storage quota exceeded",
            "action": "upgrade_required",
            "upgrade_url": "https://oelala.ai/upgrade"
        }
```

#### 2. Unauthorized (401)

```python
try:
    response = await client.put(url, headers=headers, content=data)
    response.raise_for_status()
except httpx.HTTPStatusError as e:
    if e.response.status_code == 401:
        # Token expired or invalid
        # Refresh Supabase session and retry
        result = await supabase.auth.refresh_session()
        headers["Authorization"] = f"Bearer {result.session.access_token}"
        response = await client.put(url, headers=headers, content=data)
```

#### 3. Storage Service Unavailable (503)

```python
from tenacity import retry, wait_exponential, stop_after_attempt

@retry(
    wait=wait_exponential(multiplier=1, min=4, max=10),
    stop=stop_after_attempt(3)
)
async def upload_with_retry(url: str, headers: dict, content: bytes):
    """Upload with automatic retry on transient failures."""
    async with httpx.AsyncClient() as client:
        response = await client.put(url, headers=headers, content=content)
        response.raise_for_status()
        return response.json()
```

#### 4. File Too Large

```python
MAX_FILE_SIZE = 100 * 1024 * 1024 * 1024  # 100 GB

def validate_file_size(file_path: Path) -> None:
    """Validate file size before upload."""
    size = file_path.stat().st_size
    if size > MAX_FILE_SIZE:
        raise ValueError(
            f"File too large: {size / 1024**3:.2f}GB. "
            f"Maximum: {MAX_FILE_SIZE / 1024**3:.0f}GB"
        )
```

### Complete Error Handling Example

```python
class StorageError(Exception):
    """Base exception for storage errors."""
    pass

class QuotaExceededError(StorageError):
    """Raised when user quota is exceeded."""
    pass

class UploadFailedError(StorageError):
    """Raised when upload fails."""
    pass

async def safe_upload(
    user_id: str,
    jwt_token: str,
    file_path: Path,
    media_type: str
) -> dict:
    """Upload with comprehensive error handling."""
    
    try:
        # Validate file
        validate_file_size(file_path)
        
        # Upload with StorageClient (which has retry logic via tenacity)
        async with StorageClient() as storage:
            # Check quota
            file_size = file_path.stat().st_size
            quota_check = await storage.check_quota(user_id, jwt_token, file_size)
            if not quota_check["allowed"]:
                raise QuotaExceededError(quota_check["message"])
            
            # Upload
            result = await storage.upload_generated_media(
                user_id, jwt_token, file_path, media_type
            )
        
        return result
        
    except QuotaExceededError as e:
        return {
            "success": False,
            "error": "quota_exceeded",
            "message": str(e),
            "action": "upgrade_required"
        }
    except httpx.HTTPStatusError as e:
        return {
            "success": False,
            "error": "http_error",
            "status_code": e.response.status_code,
            "message": e.response.text
        }
    except httpx.TimeoutException:
        return {
            "success": False,
            "error": "timeout",
            "message": "Upload timed out. File may be too large."
        }
    except Exception as e:
        return {
            "success": False,
            "error": "unknown",
            "message": str(e)
        }
```

## Best Practices

1. **Always authenticate**: Use JWT tokens from Supabase for all requests
2. **Check quota first**: Before generation to avoid wasting compute
3. **Use retries**: For transient network failures
4. **Log everything**: For debugging and audit trails
5. **Clean up**: Delete local files after successful upload
6. **Handle errors gracefully**: Provide clear messages to users
7. **Use timeouts**: Set appropriate timeouts for large uploads
8. **Organize files**: Use consistent path conventions
9. **Monitor usage**: Track storage consumption per user
10. **Test edge cases**: Quota limits, large files, network failures

## Troubleshooting

### Issue: 401 Unauthorized

**Cause**: Invalid or expired JWT token

**Solution**:
```python
# Refresh the session
result = await supabase.auth.refresh_session()
jwt_token = result.session.access_token
```

### Issue: 402 Payment Required

**Cause**: Storage quota exceeded

**Solution**:
1. Check current usage
2. Prompt user to upgrade tier
3. Implement cleanup of old files for free tier

### Issue: Connection refused

**Cause**: Storage service not running

**Solution**:
```bash
# Start the storage service
./oelala-storage serve
```

### Issue: Slow uploads

**Cause**: Large files or network issues

**Solutions**:
1. Implement chunked uploads for files > 100MB
2. Use compression before upload
3. Check network bandwidth
4. Consider async/background upload jobs

### Issue: File not found after upload

**Cause**: Path mismatch or sync delay

**Solution**:
1. Verify the returned storage path
2. Use the exact path from upload response
3. Add small delay for metadata sync
